# Grabbit이란?

Grabbit(그랩잇)은 크롬 웹스토어에서 4.0★·10만+ 사용자를 확보한 **링크 관리 확장 프로그램**입니다. 개발사는 MARCODE LTD. 마우스로 웹페이지의 원하는 영역을 드래그하면 그 안의 모든 링크를 한 번에 감지해 새 탭 열기·URL 복사·북마크 생성 같은 작업을 일괄 처리합니다.

::: text.callout tip
- title: "⚠️ 스크린샷 도구가 아닙니다:"
  desc: "이름이 비슷한 'Grabit'(단일 b, 스크린샷+주석+AI 이미지 검색 도구)과는 전혀 다른 별개의 확장 프로그램입니다. Grabbit은 화면 캡처가 아니라 **하이퍼링크 대량 수집**이 핵심 기능입니다."
:::

# 주요 기능

::: grid.cards
- icon: "🖱️"
  title: "드래그 추출(Drag-to-Select)"
  desc: "원하는 영역을 마우스로 드래그하면 실시간 링크 카운터와 함께 선택 영역 안의 모든 링크가 자동 감지됩니다."
- icon: "📑"
  title: "일괄 작업(Bulk Actions)"
  desc: "선택한 링크 전체를 한 번에 새 탭으로 열거나, URL을 서식과 함께 복사하거나, 북마크로 저장합니다."
- icon: "🤖"
  title: "스마트 선택(AI 필터링)"
  desc: "AI 기반 패턴 인식으로 광고·내비게이션 등 불필요한 링크를 자동으로 걸러냅니다."
- icon: "🔍"
  title: "Linkify & 방문 추적"
  desc: "일반 텍스트로 적힌 URL을 클릭 가능한 링크로 자동 변환하고, 이미 방문한 링크는 재오픈을 방지합니다."
:::

::: text.callout tip
- title: "💰 무료 기능 vs 유료(구독) AI 기능:"
  desc: "드래그 추출·일괄 작업·Linkify 등 핵심 기능은 무료입니다. 상품 비교표 생성, 기사 요약, 유튜브 영상 요약 같은 프리미엄 AI 기능은 구독이 필요합니다. 개발사는 '100% 로컬 실행'을 내세우며 추적·분석 없이 브라우징 데이터를 기기 안에만 둔다고 밝히고 있습니다."
:::

# 설치 & 사용법

::: process.steps
- title: "1크롬 웹스토어에서 \"Grabbit\" 검색 후 설치개발사 MARCODE LTD가 배포하는 확장 프로그램. 핵심 기능은 무료."
- title: "2링크가 많은 페이지에서 원하는 영역을 마우스로 드래그검색 결과, 쇼핑몰 상품 목록, 뉴스 아카이브 등에서 특히 유용."
- title: "3선택 완료 후 원하는 일괄 작업 선택전체 새 탭으로 열기 / URL 복사 / 북마크 생성 중 선택."
- title: "4반복 작업이라면 Smart Selection으로 불필요한 링크 자동 제외AI 필터링으로 매번 수동 선택 해제할 필요를 줄입니다."
:::

::: text.callout tip
- title: "💡 어울리는 용도:"
  desc: "리서치 중 검색 결과 페이지의 관련 링크를 한 번에 모아 새 탭들로 열거나, 쇼핑몰에서 상품 링크를 일괄 수집·비교할 때 특히 유용합니다. 웹페이지의 이미지 자체를 저장하는 용도는 지원하지 않으니, 이미지 다운로드가 필요하다면 별도의 이미지 다운로더 확장 프로그램을 찾아야 합니다."
:::
