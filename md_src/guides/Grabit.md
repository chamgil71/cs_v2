# Grabit이란?

Grabit은 크롬 웹스토어에 등록된 소규모 무료 확장 프로그램으로, **스크린샷 캡처 → 주석 → 저장/공유**를 한 번에 처리합니다. 개발자는 "digitalsoul"이며, 별도 대용량 이미지 다운로더가 아니라 **화면 캡처 도구**라는 점이 핵심입니다.

::: alert-box tip
- title: "⚠️ 이름이 비슷한 다른 도구와 혼동 주의:"
  desc: "이름이 비슷한 'Grabbit'(더블 b, 링크 대량 수집·관리 도구)이나 'GrabText'(OCR 텍스트 추출 확장)와는 전혀 다른 별개의 확장 프로그램입니다. 이 문서는 크롬 웹스토어의 'Grabit — Screenshot, Annotation, AI Search, Share via Link'를 기준으로 설명합니다."
:::

# 설치 & 사용법

::: step-list
- title: "1크롬 웹스토어에서 \"Grabit\" 검색 후 설치개발자 digitalsoul이 배포하는 무료 확장 프로그램. 설치 용량은 2MB 이하로 가벼움."
- title: "2캡처할 탭으로 이동 후 확장 아이콘 클릭전체 탭 또는 드래그로 원하는 영역만 선택해 캡처."
- title: "3펜 도구로 화살표·하이라이트 주석 추가설명이 필요한 부분에 바로 마킹해 의미를 명확히 전달."
- title: "4다운로드하거나 온라인에 저장해 링크 공유팀원에게 스크린샷 링크만 보내면 바로 확인 가능."
:::

::: alert-box tip
- title: "💡 어울리는 용도:"
  desc: "버그 리포트·QA 피드백처럼 '화면을 캡처하고 바로 표시해서 공유'해야 하는 짧은 커뮤니케이션에 적합합니다. 웹페이지의 이미지를 대량으로 긁어모아 저장하는 용도(이미지 다운로더)로는 설계되지 않았으니, 그런 작업이 필요하다면 별도의 이미지 다운로더 확장 프로그램을 찾는 것이 맞습니다."
:::
