# Replit Agent는 어떤 도구인가

Replit Agent는 브라우저 안에서 프롬프트 한 줄로 풀스택 웹앱을 스캐폴딩하고, 별도 배포 설정 없이 즉시 라이브 URL을 발급하는 AI 빌더입니다. Lovable·v0가 코드 소유권과 커스터마이징에 무게를 둔다면, Replit Agent는 "아이디어 → 실제로 접속 가능한 서비스"까지의 시간을 최소화하는 데 집중합니다.

# 마무리 체크리스트

- 크레딧 소모가 큰 작업(대규모 리팩토링 등)을 요청하기 전에 예상 비용을 가늠했는가?
- 프로덕션 전환 시 Replit 호스팅을 계속 쓸지, 코드를 내려받아 다른 인프라로 옮길지 결정했는가?
- 민감한 API 키나 시크릿을 Replit의 Secrets(환경변수) 기능으로 관리했는가?

> 💡 TIP: 처음부터 완성된 앱을 한 번에 요청하기보다, "로그인 기능만 먼저", "그다음 대시보드"처럼 작업을 잘게 나눠 지시하면 효율 기반 과금 구조상 비용도 아끼고 결과물 품질도 높아집니다.
